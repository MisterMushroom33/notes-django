# Заметки с темами оформления

Веб-приложение на Django для создания и просмотра заметок. Пользователь может выбирать тему оформления (светлая, тёмная, синяя), выбор сохраняется в cookies.

## Возможности

1. Просмотр списка заметок
2. Добавление новой заметки через HTML-форму
3. Переключение тем оформления
4. Сохранение выбранной темы в cookies (30 дней)

## Требования

- Python 3.12 или новее
- Git

## Установка и запуск

1. Клонировать репозиторий:

```
git clone https://github.com/MisterMushroom33/notes-django.git
cd notes-django
```

2. Создать виртуальное окружение:

```
python -m venv venv
```

3. Активировать его.

Windows (Git Bash):

```
source venv/Scripts/activate
```

Windows (cmd / PowerShell):

```
venv\Scripts\activate
```

4. Установить зависимости:

```
pip install -r requirements.txt
```

5. Запустить сервер:

```
python manage.py runserver
```

6. Открыть в браузере: http://127.0.0.1:8000/

## Структура проекта

1. `config/` - настройки проекта Django
2. `notes/` - приложение с заметками
   - `views.py` - представления
   - `urls.py` - маршруты
   - `templates/notes/` - HTML-шаблоны
   - `static/` - стили и изображения
3. `requirements.txt` - зависимости проекта
